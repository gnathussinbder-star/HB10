حزمة إصلاح موقع Hussein Badr English
=====================================
الحزمة فيها 3 ملفات:
1) HB10-site.zip  : الموقع الكامل (93 ملفا) بمجلداته: assets و levels و grammar و vocabulary. بدون أي PDF.
2) unpack.yml      : ملف صغير يفك الضغط على GitHub نفسه ويضع المجلدات في أماكنها الصحيحة.
3) README-AR.txt   : هذه الخطوات.

رابط الموقع النهائي:  https://gnathussinbder-star.github.io/HB10/

الخطوات (من الجوال أو الكمبيوتر)
--------------------------------
1) اسم المستودع لازم يكون HB10 بالضبط (Public).
   - إما تنشئ مستودعا جديدا بهذا الاسم، أو تغيّر اسم HB2 من Settings > Repository name.

2) فعّل النشر: Settings > Pages > Deploy from a branch > الفرع main > المجلد / (root) > Save.

3) أنشئ ملف الفك:
   - Add file > Create new file
   - في خانة الاسم اكتب بالضبط:  .github/workflows/unpack.yml
   - الصق كل محتوى الملف unpack.yml > Commit changes.

4) ارفع الموقع:
   - Add file > Upload files > ارفع الملف HB10-site.zip فقط (لا تفكه) > Commit changes.
   - الفك يبدأ تلقائيا.

5) تابع من تبويب Actions: انتظر علامة خضراء (حوالي دقيقة).
   - إذا لم يبدأ: Actions > Unpack site > Run workflow > Run workflow.

6) افتح الرابط بعد 2 الى 3 دقائق. إذا ظهر قديما: تحديث قوي للصفحة، أو افتحه في نافذة خاصة.

الفحص السريع بعد النشر
----------------------
- الصفحة الرئيسية بتصميمها الكامل وشعارها.
- افتح  levels.html  ثم أي مستوى (A1 ... C1): لازم تفتح.
- افتح  about.html : فيها 6 روابط حساباتك (يوتيوب، تيليجرام، إنستغرام، تيك توك، فيسبوك، لينكدإن).

ملاحظات مهمة
------------
- لا ترفع أي ملف آخر فوق index.html بعد الآن. أي إضافة جديدة ضعها في مجلدها الصحيح، ومن الأفضل رفعها من الكمبيوتر.
- بعد نجاح الفك يُحذف الملف HB10-site.zip تلقائيا من المستودع، وهذا طبيعي.
- مجلد .github ملف الفك فقط، وتقدر تحذفه لاحقا إذا حبيت.
